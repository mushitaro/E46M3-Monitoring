# KWP2000 の計画 — MS45・ME9・GS19・MK60

状態：**計画だけ**（2026-11-11）。コードは変えていない。車にもケーブルにもつないでいない。
根拠は、EDIABAS の SGBD とグループファイルを `tools/SgbdDump` で読んだものと、EdiabasLib の
シミュレーション（答えの無い送信の記録）だけ。答えは一つも見ていない。

GREN BLUE の計画の「MONITORING の範囲」（運営者 2026-10-30）：まず DS2 の車、KWP2000（MS45・ME9・GS19・MK60）は
次の段。この文書がその次の段の順番を決める。

## 0. 先に結論

1. 四つは**二つの話し方**に分かれる。
   - **DS2 の回線に KWP2000 の形を載せる**（9600 8E1、`B8 <宛先> F1 LL …`、末尾 XOR）：**MK60**（宛先 0x29）と
     **ME9 系**（宛先 0x12）。MK60 で作った `kwpOnDs2.ts` がそのまま広がる。
   - **BMW-FAST**（EDIABAS の concept 0x010F、115200 baud、`8L <宛先> F1 …`、長さは書式のバイトの下 6 ビット）：
     **MS45**（宛先 0x12）と **GS19**（宛先 0x18）。新しいトランスポートと、同じポートでの速度の切り替えが要る。
2. 変種はグループファイルが選ぶ。`D_0012` は DS2 の IDENT（`12 04 00`）が通らなければ、DS2 の回線の KWP の道
   （`B8 12 F1 01 A2`、`B8 12 F1 02 1A 80`）へ進む。これは #43 の「0xA0 でなければ KWP の道」の続きで、
   **新しいトランスポートなしで作れる**。
3. 停車の確認は、どの E46 にもある **KOMBI（0x80、DS2）の `STATUS_ANALOG_LESEN` の `STAT_GESCHWINDIGKEIT_WERT`** を
   推す。DME ごとに速度の読み方を作らずに済む。IDENT と故障の読み取りは今の決まりどおり速度を待たない。
4. 順番：**MK60 を運営者の車で答えまで確かめる → ME9 の道（DS2 の回線のまま）→ KOMBI の速度 → BMW-FAST（MS45・GS19）**。
   危ないもの（速度の切り替え・新しい書式）を最後に、一つずつ実車で確かめる。

## 1. 前提

- 送るのは **IDENT と故障の読み取りだけ**（入庫点検に要るもの）。消去・作動テスト・調整・コーディング・
  フラッシュは作らない。KWP の `$10`（診断セッション）・`$14`（消去）・`$27`（鍵）・`$2E`/`$3B`（書き込み）・
  `$30`/`$31`（作動）は送らない。
- 何を送るかは今までどおり `runGate`（`mayRun`／`mayRunProtocolRead`）一か所が決める。
- モジュールには、そのモジュールの SGBD が送るものだけ（CLAUDE.md）。グループファイルの電文をどう扱うかは §8 の
  決めること。
- この計画の変更はほぼ全部が人の承認（`autonomy:human`）の区分：電文・`runGate`・リンク・`vehicleState`・
  `packages/monitoring-engine/**`。運営者の「マージOK」を待つ時間を段取りに入れる。

## 2. 四つの ECU — 線の上で何を話すか

シミュレーションの記録（`IfhTrace=3`）から。「最初の電文」はジョブが最初に送るもので、そこで答えが無いので止まる。

| ECU | SGBD（例） | 通信方式（concept・速度） | 宛先 | IDENT の最初の電文 | 故障読み（`FS_LESEN`）の最初の電文 | 今 |
|---|---|---|---|---|---|---|
| MK60（DSC） | `DSC_MK60` | 0x0006 DS2・9600 8E1 | 0x29（線上 0xB8） | `B8 29 F1 02 1A 80` | `B8 29 F1 04 18 02 FF FF` | 識別と故障読みは実装済み（#40・#41）。答えは未観測 |
| ME9 系（DME） | `ME9K42` ほか | 0x0006 DS2・9600 8E1 | 0x12（線上 0xB8） | `B8 12 F1 02 1A 80` | `B8 12 F1 04 18 02 FF FF` | 未着手 |
| MS45（DME） | `MS450DS0` | 0x010F BMW-FAST・115200 | 0x12 | `82 12 F1 1A 80`（初期化の中で送り、SYS_0010 で止まる） | 不明（下） | 未着手 |
| GS19（AT） | `GS19` | 0x010F BMW-FAST・115200 | 0x18 | `82 18 F1 1A 80` | `84 18 F1 18 02 FF FF` | 未着手 |

- KWP のサービスは四つとも同じ：`$1A 80`（ReadECUIdentification）と `$18 02 FF FF`（ReadDTCByStatus）。
  答えの形も同じになるはず（`$5A …`／`$58 <数> <コード 2 バイト + 状態>…`、否定は `7F <SID> <理由>`）。
  **故障の解読は一つ書けば四つに効く**。
- 時間の値（EdiabasLib が読んだ通信パラメータ）：MK60 は 1000／25／20 ms（答えの最初のバイトまで／次の要求まで／
  電文の終わり）、ME9K42 は 2000／100／50 ms。BMW-FAST の二つは 800 ms・応答待ち（`7F xx 78`）の上限 5000 ms。
  各値の意味は EdiabasLib の `EdInterfaceObd.cs` の concept ごとの処理で確かめてから使う。
- `MS450DS0` は、仮想ジョブ（`_JOBS`）の表もシミュレーションでは 0 件だった（SYS_0010）。初期化が答えを要るため
  と思われる。ジョブ表と故障読みの電文は、静的な取り出し（`extract_telegrams.py` の XOR 0xF7 の読み）か、
  シミュレーションの答えのファイル（`C:\EDIABAS\SIM`）で初期化を越えさせて取る。

## 3. 変種の選び方 — グループファイル

#43（`variants.ts`・`gen_variants.py`）と同じ作り方：逆アセンブル（BESTDIS）で読む順を書き、`SgbdDump --tables` で表を取り、
`SgbdDump --ident` で EdiabasLib にグループファイルそのものを走らせ、答えの束で規則と一件でも食い違えば書かない。

| グループ | シミュレーションで送った順 | 候補の SGBD（ファイルの中の名前） |
|---|---|---|
| `D_0012`（エンジン） | `12 04 00`（DS2）→ concept 0x0006 に替えて `B8 12 F1 01 A2` → `B8 12 F1 02 1A 80` | DS2：MS42・MS43・M43・MSS52・MSS54 ほか。KWP：`MS450DS0`・`ME9K42`・`ME9K_5`・`ME9K_6`・`ME9K_NG4`・`ME9_4N`（`ME72KWP0/1` は E46 ではない） |
| `D_0032`（変速機） | `32 04 00` → `B8 32 F1 02 1A 80` | `GS19`・`GS19A`・`GS19B`・`GS20`・`SMG2` ほか多数 |
| `D_EGS` | BMW-FAST `82 18 F1 1A 80` → concept 0x010D（KWP2000・9600）`B8 18 F1 02 1A 80` → concept 0x0110（D-CAN） | `GS19`。E46 に D-CAN は無いので三つ目は使わない |
| `D_ABSKWP` | BMW-FAST `82 29 F1 1A 80` → concept 0x010D `B8 29 F1 02 1A 80` | `MK60`・`MK70` |
| `D_0056` | `56 04 00` だけ | DS2 の ABS／ASC／DSC。MK60 は無い |

分かったこと・確かめること：

- **MS45 の道が食い違う。** `D_0012` は DS2 の回線（9600）の `B8 12 F1` で KWP の DME を見分けるが、`MS450DS0` 自身は
  BMW-FAST（115200）で話す。MS45 が両方に答えるのか、`D_0012` の KWP の道は ME9 系だけのためなのかを、逆アセンブル
  （表の引き方）と実車の答えで確かめる。答えが分かるまで、MS45 を「KWP の道で答えた DME」に推測で当てない。
- `D_0012` の最初の KWP の電文は `$A2`（BMW の拡張）で、`$1A 80` の前に送る。何を読むかは逆アセンブルで確かめる。
- 変速機は、`D_0032`（DS2 の回線、宛先 0x32）と `D_EGS`（BMW-FAST、宛先 0x18）のどちらが E46 の GS19 を見つけるかを
  確かめる。GS19 の SGBD は 0x18 で話す。
- どの年式・エンジンにどれが載るかは書かない。IDENT とグループファイルの答えで決める（推測で決めない）。

## 4. 速度の源（停車の確認）

今の決まり：カタログの読み取りと消去は、送る直前に DME の車速（MSS54 のブロック 19）が 0 と読めたときだけ。
IDENT と各モジュール自身の故障の読み取りは速度を待たない（`runGate` の `fault-read`、運営者 2026-11-04）。
だから**入庫点検は速度の源が無くても成り立つ**。速度の源が要るのは、その先（カタログの読み取り・消去）。

| 候補 | 読み方 | 良いところ | 気がかり |
|---|---|---|---|
| **KOMBI（0x80）** `STATUS_ANALOG_LESEN` → `STAT_GESCHWINDIGKEIT_WERT` | DS2、今のトランスポート | どの E46 にもある。エンジンの種類に依らず一つで済む | `KOMBI46R` にはこの結果が無い。`D_0080` の変種の規則（#43 の次）が先に要る |
| DME（ME9K42）`STATUS_MESSWERTE` → `STAT_VFZG_WERT` | KWP（DS2 の回線） | 今の M3 と同じ「DME に訊く」形 | DME ごとに作る。MS45 は表が読めていない |
| GS19 `STATUS_RADGESCHWINDIGKEITEN`、MK60 `STATUS_RADGESCHWINDIGKEIT` | KWP | 車輪の速さ | AT と DSC の無い車には無い。読みたい相手そのものに先に送ることになる |

推す道：**KOMBI**。一つの読み方で非 M3 の E46 全部（DS2 の MS42/MS43・M43 と、この計画の四つ）に効き、
新しいトランスポートを待たない。DME の速度は、実車で KOMBI と並べて確かめてから二つ目の確かめに足す。

## 6. リスク

1. **答えを一度も見ていない。** 四つとも、書式は ISO 14230 の決まりからの推定。MK60 の最初の試し（2026-11-10）は
   DME の答えの直後に送って無音だった（`KWP_IDLE_MS` 150 を足した）。答えの形が違えば、解読の前に止まる。
2. **同じ回線で速度を替える。** 9600 8E1 の DS2 と 115200 8N1 の BMW-FAST を同じポートで行き来する。開き直しの
   一瞬に、ほかのモジュールが半端なバイトを受ける。`ds2-core` は速度の切り替えを「わざと持たない」と書いている
   （`byteTransport.ts`）。WebUSB の FTDI（Android・ヘッドユニット）には開き直しが無い。
3. **K+DCAN の 115200。** エコーの扱い（K ラインは送ったものが返る）、FTDI の遅延タイマ、ケーブルの K／D-CAN の
   切り替え。PC の Web Serial から始め、ヘッドユニットは後にする。
4. **グループファイルの電文は、モジュールの SGBD の表に無いことがある**（`B8 12 F1 01 A2`）。今の決まり「その
   モジュールの SGBD が送るものだけ」に当たる。§8 で運営者が決める。
5. **応答待ち（`7F xx 78`）と、診断セッション。** 待つべき答えを失敗と取って送り直すと、同じ要求が二度出る。
   今の「意味的失敗は再送しない」を守り、待ちは SGBD の上限（5000 ms）まで。`$18` の前にセッション（`$10`）が要る
   ECU があれば、それは読み取りでも送らない（§1）——読めないと記録する。
6. **MS450DS0 の表が読めていない**（§2）。カタログも故障の文も、取り出し方を先に作る。
7. **IDENT の答えに車を特定するものが入りうる。** `$1A 80` の答えの中身（部品番号、場合により VIN）は Matrix に
   渡さない（`redact`、#43 と同じ）。点検報告で VIN を照らすのは今の形のまま。
8. **人の承認の待ち時間。** 一段ごとに運営者のマージが要る。小さい PR に分ける。

## 8. 決めてほしいこと（運営者）

| 論点 | 道と、それぞれで起きること | 推す道 |
|---|---|---|
| グループファイルの電文を送ってよいか | (a) 送る：EDIABAS と同じ順で見分けられる。決まりに「グループファイルの IDENTIFIKATION が送る読みの電文」を足す ・ (b) 送らない：SGBD の `IDENT` だけで当てる。`$A2` のような見分けの電文が使えず、選べない車が残る | (a)。ただし読みのサービス（`$1A`・`$A2`・`$18`）だけ、規則が EdiabasLib と全件一致したグループだけ |
| 速度の源 | (a) KOMBI 一つ ・ (b) DME ごと ・ (c) 両方を並べる | (a) から。(c) は実車で KOMBI と DME を並べてから |
| BMW-FAST をどこまで | (a) PC の Web Serial だけ先に ・ (b) WebUSB（Android・ヘッドユニット）も同時に | (a)。開き直しの危うさを一つの経路で先に測る |
| MS45・GS19 の試験車 | GREN BLUE の在庫か、運営者の知り合いの車 | 店主と相談（この四つの車が手元に無ければ 6 は始めない） |
